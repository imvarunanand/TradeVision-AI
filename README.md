# TradeVision AI

This repository contains a production-ready scaffold for a Flutter app called TradeVision AI.

Features:
- Clean Architecture folder structure
- Riverpod state management
- Dio networking client
- Drift (SQLite) local database setup
- flutter_local_notifications initialization
- fl_chart usage
- Dark theme only

Screens included:
- Dashboard (dummy data)
- History
- Settings

To run:
1. Install Flutter stable (latest)
2. flutter pub get
3. flutter pub run build_runner build --delete-conflicting-outputs
4. flutter run
